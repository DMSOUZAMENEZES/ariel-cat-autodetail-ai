# Product Requirements Document

Objetivo: criar uma plataforma SaaS de avaliação estética automotiva com IA multimodal.

Funcionalidades:
- Cadastro de clientes
- Cadastro de veículos
- Upload de fotos
- Análise por IA
- Recomendação de serviços
- Orçamento automático
- Geração de PDF
- Envio via WhatsApp
- Dashboard

MVP:
Receber fotos, analisar, gerar orçamento e relatório.
