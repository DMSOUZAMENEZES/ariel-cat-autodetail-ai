# AI Agents

Architecture:

1. Supervisor Agent
- Receives request
- Validates photos
- Coordinates analysis

2. Vehicle Analysis Agent
- Evaluates paint
- Evaluates wheels
- Evaluates headlights
- Evaluates interior

3. Budget Agent
- Maps findings to services
- Never creates prices

4. Report Agent
- Generates structured report
- Generates PDF payload

Output format: strict JSON.
